Each `.mdx` file in `content/docs/example/` is a page. `"...example"` in `content/docs/meta.json` lists them in the *Notes* section, in the order the folder's own `meta.json` gives.

## Use a glossary term

Write a definition once in `content/glossary.json` and link to it from any note: [Static site](/docs/glossary#term-static-site).
