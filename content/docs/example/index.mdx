A note is plain Markdown. The theme styles every part of it: headings, lists, tables, code and the components below.

## Key points

- A **bold word** stands out from the paler body text.
- Links to other notes use the file path: see the [second page](./second-page.mdx).
- `inline code` for commands and names.

<Callout type="warn" title="Exam tip">
Callouts come in five types: `info`, `warn`, `error`, `success` and `idea`. Each has its own colour and icon.
</Callout>

<Callout type="idea" color="teal" icon="Sparkles" title="Your own colour and icon">
`color` takes a named colour such as `teal` or `accent`, or any CSS colour. `icon` takes any Lucide icon name.
</Callout>
